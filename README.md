# Foulée

APK Android de Foulée, carnet de course à pied personnel.

Ce dépôt ne contient que les versions publiées (onglet Releases). Le code source est privé. Les APK publiés ici ne contiennent aucune donnée personnelle.

L'application vérifie au lancement la dernière version publiée ici et propose de l'installer.
